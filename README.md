# Iğdır First-Person Exploration

Eerste groundwork-versie van een browsergame waarin je in first-person door een eenvoudige, op Iğdır geïnspireerde stad loopt.

## Starten
Open de repository in VS Code en start `index.html` met Live Server.

## Controls
- WASD: lopen
- Muis: rondkijken
- Shift: rennen
- Spatie: springen
- ESC: muis/menu vrijgeven

## Deze eerste versie
- First-person movement
- Collision
- Lange Iğdır-achtige boulevard
- Appartementen en winkelgevels
- Bomen, stoepen en straatverlichting
- Plein
- Ağrı Dağı / Mount Ararat als herkenbaar landmark op de achtergrond

De omgeving is bewust nog een blockout. Details, echte herkenningspunten en betere modellen kunnen in volgende iteraties worden toegevoegd.
